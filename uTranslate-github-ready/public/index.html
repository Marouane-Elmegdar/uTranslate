Import files

Load the original Tolgee export and the ChatGPT proposal file. They can be imported separately.

Expected structure: schema_version, project, export_metadata, translations[]. Screenshot metadata is used for review and saved in progress backups; it is omitted from the final Tolgee export.
Expected structure: { "schema_version": 1, "project": {...}, "translations": [{ "key": "...", "proposal": "...", "confidence": 0-100, "reason": "...", "issue_category": "...", "clarification_needed": false }] }. Match is by object_id, then key_id, then the exact namespace + key pair. A bare key is used only when it has one unambiguous match.
Select the folder containing the exported screenshot files if you are importing JSON separately. The tool matches images to each Tolgee entry using screenshots[].local_file, filename, or screenshot_id.

“Clarification needed” means ChatGPT believes a human must clarify the source meaning or context. It is different from “Unable to translate,” which flags a case where ChatGPT could not produce a reliable translation.

Importing a new Tolgee JSON file replaces the current source dataset. Download a progress backup first if you need to preserve decisions from the current session.
